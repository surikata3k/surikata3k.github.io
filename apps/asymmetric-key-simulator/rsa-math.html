The idea in one sentence: the public key is like an open padlock that Biel hands out to everyone; anyone can lock it, but only private key of Biel’s opens it. The two keys are linked mathematically, but the private key cannot be worked out from the public one.

    Byte a byte

    Character m (byte) c = me mod n ce mod n (Eve) cd mod n (Biel)

    Notice: the same letter always gives the same number (look at the spaces). So Eve could guess the text from letter frequencies, like a substitution cipher.

    Here each byte is encrypted separately so you can see the calculation. To avoid this, real systems encrypt large blocks with random padding (OAEP) and usually use RSA only to send a symmetric key (AES) that encrypts the rest.

    Why is it safe in real life?

    Multiplying two primes is instant; finding them from the product is very hard when they are large. All of RSA’s security rests on that difference.

    Size of nDigitsStatus
    This simulator: broken in milliseconds.
    512 bits155Factored in 1999 with hundreds of computers over months. Insecure today.
    829 bits250The public record (2020): thousands of CPU-years.
    2048 bits617Minimum recommended size today. Out of reach of current computers.
    4096 bits1233More margin, at the cost of being slower.

    A large enough quantum computer could factor n with Shor’s algorithm. That is why post-quantum algorithms (such as ML-KEM) that don’t rely on this problem are already being adopted.
