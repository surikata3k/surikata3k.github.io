Which key do you use?

What is asymmetric cryptography?

Asymmetric, or public-key, cryptography uses a key pair: a public key that can be shared with anyone, and a private key that only its owner has. What is encrypted with the public key can only be decrypted with the private key, and what is signed with the private key can be verified with the public key.

The simulator explains it with padlocks and keys in four scenarios: sending a secret, replying, signing a message and spotting a man-in-the-middle attack. At the end, a quiz checks whether you know which key to use in each case.

Where it is used

  • HTTPS: each website’s public key arrives inside a certificate.
  • SSH: your public key is copied to the server in authorized_keys.
  • Signing emails and documents: GPG, PGP and e-signatures.

frequently asked questions

Which key encrypts and which decrypts?+

You encrypt with the recipient’s public key, and they decrypt with their private key.

And for signing a message?+

The other way round: you sign with your own private key and anyone can verify the signature with your public key.

What is a man-in-the-middle attack?+

An attacker gets in between and hands over their own public key while pretending to be someone else. You prevent it by checking that the key really belongs to who it claims, using certificates or its fingerprint.
