How to tell if a password is strong

The checker measures the password’s length, character types and entropy, and estimates how long an attacker would need to find it by trying every combination. It also looks for weak patterns that entropy misses: common words, sequences such as “123” or “qwerty”, repeated characters and years.

The check runs in your browser and the password is never sent anywhere. Even so, to test a password you actually use, it’s a good idea to try a similar one instead of the real thing.

What each indicator means

  • Entropy: how many bits of uncertainty it has; every bit doubles the combinations.
  • Character set: how many different characters each position could hold.
  • Brute-force time: depends on the attacker hardware you pick in the list.

frequently asked questions

What is password entropy?+

A measure, in bits, of how unpredictable a password is. Every bit doubles the number of combinations: 60 bits is already more than a billion billion possibilities.

Why can a high-entropy password still be weak?+

Because the calculation assumes every character is random. “Barcelona2024!” looks complex, but a dictionary attack tries words, names and years first and finds it quickly.

How long does it take to crack a password?+

It depends on its length and on how the service stores it. With slow algorithms such as bcrypt, an attacker tries thousands of passwords per second; with fast hashes, billions.
