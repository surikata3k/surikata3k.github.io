Hash SHA-256

A hash is the digital fingerprint of some data: it always has 64 hexadecimal characters (256 bits), the same input always gives the same hash, and changing a single letter changes it completely.

A block and mining

The block hash is calculated from the number, the nonce and the data. The block is valid (green) when the hash starts with the zeros the difficulty requires. If you change the data, the block is no longer valid: press Mine to brute-force a new nonce.

The chain

Each block stores the hash of the previous block. If you modify an old block, its hash changes and breaks every block after it. To forge history you would have to re-mine the rest of the chain.

Distributed network

Three nodes keep a copy of the same chain. Modify and re-mine the chain on a single node: its last hash will no longer match the others, and the majority of the network will reject it.

Tokens

In a cryptocurrency, the data in each block are transactions. Try increasing the amount of an old transaction: everything after it becomes invalid.

How a blockchain works

A blockchain is a list of linked blocks: each block stores its data and the hash of the previous block. If someone modifies an old block, its hash changes and no longer matches the one stored in the next block, so the tampering is obvious.

To make adding blocks costly, proof of work requires finding a nonce that makes the hash start with several zeros. Finding it takes many attempts, but checking it is instant. And because the chain is copied across many nodes, an attacker would have to re-mine every block and convince the majority of the network.

Frequently asked questions

What is a SHA-256 hash?

A function that turns any data into 64 hexadecimal characters. The same data always gives the same hash, changing one character changes it completely, and you can’t go back from the hash to the original data.

What does mining a block mean?

Trying nonce values until the hash meets the difficulty. In the simulator, difficulty 4 requires the hash to start with 0000, which takes about 65,000 attempts on average.

Why is a blockchain so hard to forge?

Because you would have to re-mine the modified block and every block after it, and also get the majority of nodes to accept the new version.
