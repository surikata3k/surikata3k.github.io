La idea en una frase: la clave pública es como un candado abierto que Biel reparte a todo el mundo; cualquiera puede cerrarlo, pero solo la clave privada de Biel lo abre. Las dos claves están ligadas matemáticamente, pero de la pública no se puede deducir la privada.

    Byte a byte

    Carácter m (byte) c = me mod n ce mod n (Eva) cd mod n (Biel)

    Fíjate: la misma letra siempre da el mismo número (mira los espacios). Así Eva podría adivinar el texto por frecuencias, como en un cifrado por sustitución.

    Aquí se cifra cada byte por separado para que se vea el cálculo. Para evitarlo, los sistemas reales cifran bloques grandes con relleno aleatorio (OAEP) y normalmente usan RSA solo para enviar una clave simétrica (AES) que cifra el resto.

    ¿Por qué es seguro en la vida real?

    Multiplicar dos primos es instantáneo; encontrarlos a partir del producto es muy difícil cuando son grandes. Toda la seguridad de RSA se basa en esa diferencia.

    Un ordenador cuántico lo bastante grande podría factorizar n con el algoritmo de Shor. Por eso ya se están adoptando algoritmos poscuánticos (como ML-KEM) que no dependen de ese problema.
